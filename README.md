# DEAD LETTER OFFICE

Небольшой офлайн roguelike о ночной сортировке сверхъестественной почты. Все интерфейсные тексты — на русском; игра работает без сервера и внешних сервисов.

## Запуск

Откройте [`index.html`](./index.html) в современном браузере. Для локального сервера (не обязательно, но удобно для сохранения в некоторых настройках браузера):

```powershell
py -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Управление

- Клик по посылке — осмотр и выбор.
- Клик по карте — применить карту к выбранной посылке.
- **1 / 2 / 3** — переслать / архивировать / изолировать.
- **Space** — завершить ход и продвинуть ленты.
- **Esc** — пауза.
- **R** — справочник учреждения.

Прогресс текущего дела сохраняется в `localStorage` между сменами.
