# Visual prototype previews

The three prototypes are switchable in the title screen under **ВИЗУАЛЬНЫЙ ЦЕХ**. The selector persists locally and does not modify the game state.

For a fresh comparison:

1. Open `index.html` in a modern browser.
2. Choose A, B, or C on the title screen.
3. Open **Реестр дел**, dismiss the briefing, and compare the same opening state.
4. Capture the first viewport at 1920×1080, 1366×768, and 820×700 if you are creating review evidence.
